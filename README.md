# Reflector Tracker v5.31 — модульная версия

Запуск: `python run_tracker.py`.

Модули:

- `detection.py` — выделение яркого ядра и Night-шаблон отражателя;
- `tracking.py` — фильтрация, HOLD/LOST и подтвержденный перезахват;
- `ir_calibration.py` — строгая калибровка Day ↔ Night внутри каждой Pn;
- `calibration.py` — настройки, пресеты и совместимость JSON;
- `camera.py`, `hikvision.py` — видеопоток и управление камерой;
- `recording.py`, `recording_controls.py` — запись окна и состояния;
- `view.py`, `ui_setup.py`, `settings.py`, `region_selection.py`, `display.py` — интерфейс.

v5.31 использует ту же модель обнаружения, что и v5.30: повторять Day ↔ Night ×2
после обновления только ради интерфейса не нужно. Повтор нужен лишь для
моделей, созданных до v5.30.

## Исправление v5.30

Подтвержденная координата Day↔Night больше не заменяется повторным центром
Night-детектора. Разница методов измерения хранится как служебная поправка,
поэтому маркер не прыгает после исчезновения диагностического слоя.

## Исправление v5.30

Состояние `LOST:NO_OFFSET` заменено автоматической трехкадровой калибровкой
служебной поправки. Подтвержденный Day↔Night-маркер остается на месте.

## Исправление v5.30

Центр сопровождения определяется корреляцией сохраненного изображения всего
ромбовидного ореола. Изменение яркости отдельных лучей больше не двигает маркер.
Нулевая координата задается подтвержденным Day↔Night-центром.

## Интерфейс v5.31

- залитая красная точка заменена точным наклонным крестиком;
- базовый вид состоит из текущего и стартового крестиков;
- фактическая яркая маска, по которой вычислен центр, вынесена в отдельный контурный слой;
- подписи, круги, рамки, линии, числа смещений и общая строка включаются независимо.
